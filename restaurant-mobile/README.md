# Atlas Restaurant

Самостоятельное приложение React Native / Expo для владельцев и менеджеров ресторанов. Эта папка содержит собственные исходники, зависимости, фотографии, шрифты через npm, конфигурацию, тесты и Android-проект. Импортов из `mobile`, ссылок на его `node_modules` и переключателя `APP_VARIANT` нет. Папку можно перенести в отдельный репозиторий.

## Запуск и сборка

Требуются Node.js, Android SDK и JDK 17 или новее, совместимый с Gradle проекта.

```sh
npm ci
npm run typecheck
npm test
npm run android
npm run build:apk
```

APK появляется в `builds/Atlas-Restaurant-<версия>.apk`. При необходимости задать Android SDK создайте `android/local.properties` со строкой `sdk.dir=...` или используйте `ANDROID_HOME`. Свой Android-проект можно восстановить командой `npm run prebuild:android`. Для iOS выполняйте `npm run prebuild -- --platform ios` на macOS, затем `npm run ios`.

Сохранены Android package и iOS bundle identifier `kg.taxigo.restaurant`, схема `atlas-restaurant` и ключ сессии `atlas.restaurant.session.v1`. Для обновления установленного APK нужно использовать прежний ключ подписи. В текущем локальном Android-проекте сохранена совместимая подпись предыдущего APK; keystore не хранится в Git. Для новой рабочей машины перенесите ключ отдельно или настройте собственную release-подпись.

## Сервер и доступ

Приложение обращается к действующему Atlas API через `/restaurant/*`; адрес указан в `config/api.cjs` и может быть переопределён `EXPO_PUBLIC_API_URL` (пример в `.env.example`). Backend и админка остаются сервисами платформы: регистрация владельцев, права, каталог и передача заказов водителям выполняются через API, а не через исходники другого приложения.

Владельца создаёт администратор Atlas по телефону и паролю. Владелец добавляет менеджеров и выдаёт права. По умолчанию менеджер работает только с заказами. Доступны меню с модификаторами и фотографиями, категории, акции, условия доставки, сотрудники, статистика, доставка своим курьером или машиной Atlas.

Новые заказы обновляются в активном приложении с баннером и вибрацией. Фоновые push пока не подключены; для них потребуется конфигурация Firebase этого приложения. EAS-профили находятся в собственном `eas.json`; при использовании EAS задайте отдельный `EXPO_PUBLIC_RESTAURANT_EAS_PROJECT_ID`.

Источники тестовых фотографий: `assets/food/photography/SOURCES.md`. Эти файлы принадлежат этому проекту и не загружаются из клиентского приложения во время сборки.
