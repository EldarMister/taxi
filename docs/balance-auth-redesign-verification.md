# Баланс и авторизация — редизайн и проверка

Референсы: `designe/новый uiux/новый баланс.png`, `новый экран авторизации.png`, `новый экран ввода кода.png`. Изображения открыты до реализации. Масштаб принят примерно за 2 физических пикселя на dp: основная проверка — 426 dp (852 × 1848), дополнительная — 360 dp (720 × 1280).

## Изменения

- `DriverBalanceScreen.tsx`: светлый фон, компактная шапка и кошелёк, центрированный депозит, отдельные показатели наличных и комиссии, строки операций с датой, остатком и исходным знаком суммы. Используются существующие загрузка, обновление и API `/driver/balance`, без повторного вычитания комиссии.
- `AuthScreen.tsx`, `auth/design.ts`, `auth/AuthMotion.tsx`: существующий логотип ATLAS, Inter, согласованные цвета и размеры, поле телефона и состояния кнопки, шесть ячеек кода, компактный выбор языка. Юридический блок сохранён на телефоне и удалён только на коде. URL документов по-прежнему берутся из конфигурации приложения.
- Ввод нормализует телефон и код, поддерживает вставку, удаление, следующий активный разряд и автоматическое подтверждение. Сохранены блокировка параллельных запросов, ошибки, серверный таймер, смена номера и показ тестового кода только при `development: true` в ответе сервера.
- На Android измеряется фактическое перекрытие клавиатурой; на iOS сохранено штатное избегание клавиатуры. Форма прокручивается для доступа к кнопке. После закрытия клавиатуры восстанавливается полная высота.
- Общая шапка и нижняя панель водителя скрыты на балансе, как на референсе; собственная кнопка меню открывает существующее меню приложения.

Финансовые расчёты и серверная выдача не изменялись. API ранее возвращал последние 100 операций без отдельного курсора; этот контракт сохранён. Проверка списка из 100 операций подтверждает, что экран отображает всю полученную выдачу.

## Проверки

- `npm --prefix mobile run typecheck` — успешно.
- `npm --prefix mobile run test:auth` — 23/23: нормализация номера, отправка, ошибки, вставка кода, удаление и фокус, автоподтверждение, защита повторных запросов, таймер, повторная отправка, смена номера, язык и тема, клавиатура и очистка обработчиков.
- `npm --prefix mobile run test:balance` — 2/2: независимость финансовых значений, положительные и отрицательные операции, остатки, 100 строк, обновление, меню, загрузка и пустой список.
- `npm --prefix mobile run test:account` — 17/17: существующие функции профиля, настроек, темы, языка и уведомлений.
- `npm --prefix mobile run test:ui` — 1/1: структура текста React Native корректна.
- `npm --prefix mobile run test:native` — 141/142. Ранее существовавшая ошибка: тест чата ожидает буквальный `behavior="padding"`, хотя чат использует выбор поведения по платформе. Код чата в этой задаче не менялся.

В Android-эмуляторе пройден настоящий путь через локальный API: телефон → запрос кода → частичный ввод и удаление → подтверждение → баланс. Проверены реальный отсчёт 60 секунд и повторная отправка со сбросом ввода и таймера, изменение номера, переключение языка и сохранение выбранного языка при повторном открытии. Серверное ограничение частоты запросов также возвращает видимую ошибку, без обхода ограничений. API и база для проверки — изолированная локальная копия, рабочий внешний сервер не использовался.

Баланс проверен на существующих данных: депозит 986 сом, доход 133 сом, комиссия 14 сом; операции −14 и +1000 сом с остатками из API. После подтверждения другого существующего водителя также проверен баланс с депозитом 1000 сом и нулевым доходом. На ширине 360 dp проверены прокрутка до последней операции и доступность формы с клавиатурой.
