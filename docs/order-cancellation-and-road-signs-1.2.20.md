# Отмена принятого заказа и подложки знаков — 1.2.20

Отмена водителем принятого заказа раньше возвращала заказ в `SEARCHING`, отсоединяла водителя и запускала распределение другим водителям. Если продолжение поиска не находило исполнителя, клиент получал `NO_DRIVER` и панель «Водитель не найден». Теперь отмена — окончательный статус `CANCELLED` для клиента и водителя, без повторного поиска. Клиент получает существующую модалку «Заказ отменён» с красной круглой 3D-иллюстрацией, кнопками «Заказать снова» и «Закрыть».

На сервере сохраняется назначенный водитель для истории и доступа к результату отмены. Предложения помечаются пропущенными, участники получают обновление, другим предложенным водителям отправляется отзыв предложения. Повторная отмена участником идемпотентна, новая запись истории и задания push повторно не создаются. `NO_DRIVER` остаётся результатом неуспешного первоначального поиска.

Назначенный водитель теперь может отменить заказ в `IN_PROGRESS`; клиенту отмена после начала поездки по-прежнему недоступна. Завершённый заказ отменить нельзя. Отмена не списывает комиссию и не учитывается как выполненная поездка. Заказ закрывается, и водитель может принять новый. Доставка ресторана использует существующее восстановление состояния еды `READY`, без автоматического повторного назначения курьера.

Водительская кнопка «Отменить заказ» вынесена в постоянный footer панели ожидания и начатой поездки; для доставки она также доступна после начала. Раскрывать детали не нужно. Сохраняется отдельное подтверждение отмены с возвратом назад. Кнопка блокируется при запросе, зона нажатия — минимум 44 пункта. Резервный `TripPanel` также допускает водительскую отмену начатой поездки.

У дорожных предупреждений на карте удалены фон карточки, рамка, скруглённая подложка и тень контейнера. Сохранены изображения знаков и расстояние; небольшая тень текста помогает читать расстояние поверх карты в светлой и тёмной темах. Изображения самих дорожных знаков не изменены.

## Проверки

- 71 мобильная проверка прошла: панели, модалка отмены, восстановление маршрута, движение панели и дорожные предупреждения. Новый сценарий выполняет отмену из свёрнутой панели для такси, легковой и грузовой доставки, проверяет подтверждение, возврат назад, блокировку при запросе и закрытие подтверждения после `CANCELLED`.
- 5 проверок через настоящие HTTP API, WebSocket и локальный PostgreSQL прошли: окончательная отмена принятого заказа без распределения; водительская отмена начатой поездки, три одновременных подтверждения без дублей и комиссии, запрет другому водителю/клиенту; обычное завершение с единственной комиссией; отмена при платном ожидании; первоначальный поиск без водителей по-прежнему заканчивается `NO_DRIVER`.
- Проверка TypeScript мобильного приложения и сборка TypeScript сервера прошли.
- Исправлена нестабильность тестового ожидания chat-событий: ожидание ответа/фотографии фильтруется по `clientMessageId`, чтобы задержавшееся собственное сообщение не принималось за ответ. Код чата приложения и сервера не менялся.
- Использовалась отдельная база `atlas_order_cancel_taxi_test` на `127.0.0.1:55441`, development-провайдеры SMS/push и локальные секреты. Рабочая база не изменялась тестами, реальные SMS/push не отправлялись. После проверки локальный PostgreSQL остановлен.
- На физическом Android-телефоне эта версия ещё не проверена.
