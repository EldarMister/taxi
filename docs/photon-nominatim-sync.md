# Photon обновляется из нашей Nominatim

Настроено и проверено на production 15 октября 2026 года.

Поиск больше не ждёт публикации готового регионального дампа GraphHopper. Photon читает завершённую геобазу Nominatim и строит отдельный индекс Кыргызстана с языками `ru,ky,en`. Это полный импорт региона при изменении даты исходной базы; инкрементальные триггеры и права записи Photon в Nominatim не требуются.

## Работа обновлений

`deploy/photon/sync.py` каждые 900 секунд проверяет `import_status.lastimportdate` и `indexed`. При той же дате импорт пропускается. Если база изменилась, менеджер берёт PostgreSQL advisory lock `704031935517`. Этот же lock использует новый координатор `deploy/nominatim/replication.py`, запускающий `nominatim replication --once`. Репликация и импорт Photon выполняются по очереди.

Новый индекс создаётся в отдельном `/data/indices/nominatim.*`, старый продолжает обслуживать поиск. Перед переключением временный сервер проверяет `/status`, совпадение даты с Nominatim и выдачу Бишкек/Шамалды-Сай. Ссылка `/data/current` заменяется атомарно, основной сервер перечитывает новый индекс. При неудачной проверке рабочего сервера восстанавливается прежняя ссылка. Предыдущий индекс сохраняется; удаляются только более старые индексы с маркером нашего менеджера. Импорт ограничен 1800 секундами; зависший дочерний процесс останавливается до освобождения замка.

Полная свежесть определяется входными обновлениями самой Nominatim. После них добавляется ожидание следующей проверки Photon, время импорта и до 10 минут кэша отдельных запросов API. Если источник не изменился, нет периодической пересборки одинакового индекса.

## Доступ к базе

На Nominatim создана роль `photon_reader`: SELECT на геотаблицы, `default_transaction_read_only=on`, без INSERT/UPDATE/DELETE, superuser, createdb, createrole или replication. Пароль хранится в закрытых переменных Photon в Railway. PostgreSQL использует существующую приватную сеть; добавлено отдельное IPv6-правило SCRAM только для этой роли и базы `nominatim`. Публичный TCP proxy не создавался.

Подготовлен индекс `atlas_photon_country_code` через `CREATE INDEX CONCURRENTLY`, чтобы импорт работал с read-only ролью. Перед настройкой создана полная резервная копия Nominatim и проверен список её архива. Схема API, данные пользователей/заказов и APK не менялись в этом задании. Endpoint `/nominatim-update` не включается.
