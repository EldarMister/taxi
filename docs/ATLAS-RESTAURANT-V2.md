# Atlas Restaurant V2 — реализация и проверка

Дата: 12 октября 2026. Ветка: `feature/atlas-restaurant-v2`. Самостоятельное приложение: `apps/atlas-restaurant`, версия 2.0.0.

## Что реализовано

- Новый frontend с собственной архитектурой и шестью разделами: главная, заказы, меню, акции, цифры, ресторан.
- Стиль фактических экранов клиентского Atlas: синий `#087FFF`, фон `#F7F7F5`, Inter, крупные скругления, фотографии, нижняя навигация и sheets. Частые операции не задерживаются декоративной анимацией.
- Экран входа обновлён по предоставленному макету `designe/дизайн приложения ресторана/Вход в ресторан Atlas.png`: светлый фон, оригинальный графический логотип, поля с иконками и показом пароля, синяя кнопка и пояснения о доступе. `assets/brand/atlas-logo.png` — точная копия исходного `mobile/assets/logo light.png`, подтверждённая SHA-256; графический знак также используется в шапке и при загрузке приложения. Введённые данные сохраняются при ошибке авторизации.
- Dashboard: ресторан и статус, остановка приёма, новые/готовящиеся заказы, выручка и средний чек дня, действия добавления блюда/акции, стоп-лист и популярные блюда.
- Меню: категории, порядок, поиск, стоп-лист, все поддерживаемые поля блюда, состав/БЖУ, два фото с кадрированием и оптимизацией, доступность без полного редактора.
- Модификаторы: группы, обязательность, min/max, цена, область применения цены, варианты по умолчанию. Изменение общего модификатора для одного блюда не меняет остальные блюда.
- «Как видит клиент»: фото, описание, состав, БЖУ, выбор добавок, количество и пересчёт цены с действующими скидками карточки. Правила выбора лучшей акции, округления и цены добавок сверены с клиентским Atlas и сервером; акции с порогом суммы остаются расчётом корзины.
- Заказы: клиент/телефон, позиции и добавки, адрес/координаты, комментарий, получение, наличные, история, курьер и разрешённые сервером действия.
- Доставка: собственный курьер и существующий Atlas quote → цена → подтверждение → dispatch. Проверка неопределённого результата и защита повторного вызова машины.
- Акции всех трёх серверных типов, сроки по времени Бишкека, минимальная сумма, конкретные блюда, включение/выключение и предпросмотр.
- Профиль ресторана, фотографии/обложка, координаты, контакты, условия доставки; рейтинг и отзывы только для чтения.
- Менеджеры: создание, изменение, права, активация/деактивация, ограничение выдаваемых прав и запрет изменения собственного доступа.
- Аналитика из API: четыре периода, выручка, заказы, средний чек, завершённые/отменённые и диаграмма по дням.
- SecureStore, восстановление/миграция сессии, один refresh при параллельных 401, защита запоздалых ответов при смене аккаунта/ресторана, polling с reconnect, foreground-вибрация и визуальные уведомления.

## Использованные API

Все пути ниже относительно существующего `/api/restaurant`. Ресторанный токен имеет отдельную серверную аудиторию.

| Метод и путь | Применение |
|---|---|
| `POST /auth/login`, `/auth/refresh`, `/auth/logout` | Сессия |
| `GET /me` | Профиль и актуальные права |
| `GET /:id` | Каталог ресторана и версия |
| `PUT /:id/catalog` | Блюда, категории, модификаторы, профиль, доставка, акции; `updatedAt` обязателен в новом клиенте |
| `POST /:id/media` | Multipart фото, максимум 8 МБ |
| `GET /:id/orders` | Только заказы выбранного ресторана |
| `PATCH /:id/orders/:orderId` | `ACCEPT`, `PREPARING`, `READY`, `COMPLETE`, `CANCEL` |
| `POST /:id/orders/:orderId/dispatch-quote` | Предварительная стоимость существующей доставки Atlas |
| `POST /:id/orders/:orderId/dispatch` | `OWN` либо `ATLAS_CAR`, согласованная `expectedPrice` |
| `GET /:id/stats?period=day\|week\|month\|all` | Аналитика |
| `GET`, `POST /:id/staff`; `PATCH`, `DELETE /:id/staff/:accountId` | Сотрудники |

Единственное изменение production backend — в `server/src/restaurant.ts`: существующий запрос заказов дополнен чтением хронологической истории (`id`, `status`, `reason`, `createdAt`) и контактов назначенного водителя (`name`, `phone`). Фильтр ресторана и проверка `orders.read` сохранены. Схема БД, миграции, checkout, модель статусов, тарифы, оплата и логика акций не изменены.

## Границы выпуска

Нет расписания и независимой доступности категорий в текущем API; нет background push и онлайн-оплаты; нет API публикации отзывов. Последние 200 заказов ограничивают ленту, восстановление очень долгого отключения и расчёт популярных блюд; полная аналитика берётся отдельным API. Web хранит авторизацию только в памяти. Для APK/IPA обновления существующего приложения нужны его исходные signing credentials. Физические устройства, фон, вибрация и iOS native runtime требуют отдельной проверки. Подробные команды запуска и выпуска находятся в `apps/atlas-restaurant/README.md`.
