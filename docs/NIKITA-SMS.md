# Вход Atlas через SMSPRO Nikita

Основной провайдер: `SMS_PROVIDER=nikita`. Отправка через WhatsApp и Telegram
для новых запросов при этом не выполняется. Ключ находится только на сервере.

## Кабинет SMSPRO

- Согласованный отправитель; в тестовом аккаунте доступен `SMSPRO.KG`.
- Код: шесть цифр, срок действия пять минут.
- Текст: `Atlas: ваш код %code%. Никому не сообщайте его.`
- Сохранить настройки в разделе «Сервис OTP».
- Пока аккаунт в тестовом режиме, отправка разрешена только на номер профиля.
  Имя Atlas и возможность отправки остальным клиентам требуют согласования Nikita.

## Настройки сервера

```dotenv
SMS_PROVIDER=nikita
DEV_AUTH_ENABLED=false
NIKITA_API_KEY=<ключ из Сервис OTP, не ключ Altegio>
# Только перечисленные аккаунты получают локальный тестовый код.
TEST_AUTH_PHONES=+996700111111,+996220203083,+996220203084
TEST_AUTH_CODE=<действующий тестовый код>
```

Ключи сохраняются в игнорируемом файле `.local/smspro/activation.env`, затем
в закрытых переменных сервиса API в Railway. Они не включаются в APK, сайт,
Git или диагностические сообщения. Ключ Altegio со служебным суффиксом не
используется для OTP.

## Работа

Сервер вызывает `POST https://smspro.nikita.kg/api/otp/send` с `X-API-KEY`,
международным номером без плюса и уникальным 32-символьным `transaction_id`.
Код генерирует Nikita. Запрос активируется только при `status=0` и наличии
корректного токена транзакции. Наружу возвращаются `channel=sms` и таймер 60 секунд.

Токен Nikita хранится в `SmsChallenge.providerTokenCiphertext`: AES-256-GCM,
отдельный ключ из OTP_SECRET, привязка к телефону и конкретному запросу.
Введённый код проверяется сервером через `/api/otp/verify`. Ответы `0` и `"0"`
означают успешную проверку; `14` — неверный код, `12/13` — недействительный
или истёкший запрос. Ошибки доступа, сети и неизвестные ответы не дают входа
и не считаются ошибкой пользователя.

Сохранены лимиты: одна отправка в минуту, пять в час на номер, двадцать в час
на IP; максимум пять неправильных кодов и пять минут на запрос. Проверка
сериализуется блокировкой строки БД. Токен очищается после входа, исчерпания
попыток, истечения срока и при замене запроса. Внешние запросы не повторяются
автоматически после таймаута, чтобы не отправить и не оплатить SMS дважды.

Миграция `20261009180000_nikita_sms_otp` добавляет два поля с сохранением
старых запросов и существующей схемы авторизации. Изменения приложения для
обычного ввода/вставки SMS-кода не нужны: текущий экран уже поддерживает `sms`.

## Проверки

`npm run build`, `npm run test:auth` в server и
`node --test tests/auth-flow.test.cjs` в mobile. Проверяются принятие запроса,
вход, одноразовость, повторная отправка, шифрование, срок жизни, неверные коды,
ошибки сервиса, отдельный вход существующих тестовых аккаунтов и отправку остальных номеров провайдеру.
Реальный тест выполняется один раз на разрешённом номере с ручным вводом
полученного кода; без ответа получателя доставка/вход не считаются проверенными.

Документация: https://smspro.nikita.kg/kg/documents/smspro.nikita.kg-OTP-api.pdf

## Результат подключения 9 октября 2026

- В сервисе API Railway включён `SMS_PROVIDER=nikita`, тестовый вход отключён.
- Развёртывание `fb2532c6-dc35-4a02-ba47-f947730b90ba` завершено успешно;
  миграция применена, проверка здоровья возвращает 200.
- Кабинет Nikita: `SMSPRO.KG`, шесть цифр, пять минут, текст Atlas сохранён;
  имя Atlas находится на модерации, аккаунт остаётся в тестовом режиме.
- Ограничение `NIKITA_TEST_PHONE` на сервере удалено. Ограничения тестового
  кабинета действуют на стороне Nikita. Указанные тестовые аккаунты
  используют отдельный локальный код без отправки SMS; остальные — Nikita.
  Удалённые аккаунты и администраторы не получают тестовый вход.
- Реальный запрос `/api/auth/request-code` вернул 201, `channel=sms`, таймер 60
  секунд без development-кода. Получатель подтвердил получение SMS.
- 49 серверных проверок авторизации, 34 проверки экрана входа и сборка прошли.
  Реальная проверка полученного кода не выполнялась: получатель подтвердил
  доставку, но сам код для теста не предоставлял. Успешная проверка, ошибочный
  код, истечение, повторное использование и повторная отправка покрыты тестами.
- Новый APK для обычного SMS-входа не требуется.

## Исправление тестового входа

52 серверные проверки авторизации, 35 проверок экрана входа и сборка прошли.
Подпись о подстановке WhatsApp под «Продолжить» удалена из мобильного экрана.
Для этого визуального изменения требуется обновлённая сборка приложения.

Тестовые номера поддерживают также первый вход и регистрацию. Это исключение
действует только для явно перечисленных номеров; удалённые аккаунты исключены.
