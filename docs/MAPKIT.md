# Yandex MapKit: маршрут A → B

Приложение использует Yandex Mobile SDK MapKit только для открытой клиенту карты, поиска/выбора точек подачи и назначения и отображения автомобильного маршрута между ними. Машины, люди и другие перемещающиеся объекты на карте не отслеживаются. Фоновая геолокация водителя, передача его координат и маркер движущегося автомобиля отключены.

## Бесплатный ключ

По официальным условиям, проверенным 5 сентября 2026 года, бесплатную версию MapKit можно использовать при одновременном соблюдении условий:

- приложение доступно для бесплатного открытого использования; обычная регистрация не считается закрытием доступа;
- карту открывают не более 1 000 уникальных пользователей в сутки;
- маршрут показывается внутри приложения на карте MapKit, а не на карте другого поставщика;
- логотип, копирайты и кнопка «Открыть в Картах» не скрываются;
- в разделе приложения размещена ссылка с названием «Условия использования сервиса Яндекс.Карты»;
- данные Яндекса не используются для мониторинга транспорта, людей, диспетчеризации или навигационного ведения.

Источники: [условия использования API Яндекс Карт](https://yandex.ru/legal/maps_api/ru/), [тариф MapKit](https://yandex.ru/dev/tariffs/doc/ru/mapkit/prices/), [страница продукта MapKit](https://yandex.ru/maps-api/products/mapkit).

В Taxi GO уже есть кнопка «Открыть в Картах» и ссылка на условия в разделе поддержки. Владелец ключа должен принять актуальные условия в кабинете Яндекса и следить за DAU. При превышении 1 000 DAU или изменении сценария использования потребуется пересмотреть тариф.

## Подключение

1. Создайте продукт Mobile SDK MapKit в [кабинете разработчика Яндекса](https://developer.tech.yandex.ru/).
2. Ограничьте ключ идентификатором приложения `kg.taxigo.app` для Android и iOS.
3. Запишите ключ в `mobile/.env`:

```env
EXPO_PUBLIC_YANDEX_MAPKIT_KEY=ваш_ключ
```

4. Пересоберите приложение. На Android и iOS ключ встраивается в нативную сборку, поэтому перезапуска Metro недостаточно.

```powershell
cd mobile
npx expo prebuild --platform android
npm run android
```

На Mac для iOS:

```sh
cd mobile
npx expo prebuild --platform ios
npm run ios
```

Используется `react-native-yamap` 4.8.3 и MapKit 4.8.0-full. Скрипт `mobile/scripts/patch-yamap.cjs` автоматически применяет совместимость с React Native 0.81 после установки зависимостей.

## Маршрут и стоимость

MapKit строит красивую линию маршрута A → B непосредственно на устройстве. Этот результат не отправляется на сервер и не используется как доверенная цена.

По умолчанию сервер использует `ROUTING_PROVIDER=approximation`: рассчитывает контрольную дистанцию по координатам с дорожным коэффициентом и фиксирует цену по серверному тарифу. Для небольшого городского MVP это не требует отдельного серверного ключа Яндекса, но расстояние и время будут приблизительными.

Если позднее понадобится точная серверная дистанция для тарификации, настройте отдельный Router API и `ROUTING_PROVIDER=yandex`. Бесплатный мобильный ключ MapKit не является серверным ключом Router API.

## Геолокация

Разрешение местоположения запрашивается только в активном приложении, когда клиент нажимает «Моё местоположение». Водитель выходит на линию без GPS. Заказы предлагаются свободным подтверждённым водителям на линии; расстояние до машины и время её подачи не вычисляются.

Для Android остаются только `ACCESS_COARSE_LOCATION` и `ACCESS_FINE_LOCATION`. `ACCESS_BACKGROUND_LOCATION`, фоновая задача и foreground service удалены. На iOS background location отключена.

## Проверка

`npm --prefix mobile run test:native` проверяет, что фоновые разрешения, отправка координат и маркер машины не вернулись, а MapKit по-прежнему строит маршрут между двумя точками. Реальное качество карты, поиска и маршрутов нужно проверить на собственном ключе в обслуживаемых районах Бишкека.
