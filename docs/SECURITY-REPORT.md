Это доказательство только состава этих JS-артефактов, не безопасности всех native/OTA/signing путей. Обязательный full dependency audit не ослаблен и остаётся failed. Автоматический downgrade Expo/RN или исключение advisories не выполнялись. Прямой путь эксплуатации этих двух advisories в просмотренном API не найден; обновление всего Firebase major без отдельной проверки поведения push не выполнялось. Это оценка локального пути, не доказательство безопасности неизвестного production-образа.

## Стоимость и качество

Ранее прочитанный расход проекта за завершавшийся период 13 сентября–13 октября: около $14.09 usage; карты около $10.66 (75.6%), RAM около 92.7% всего usage. Это исторический снимок, не будущий счёт и не стоимость всего workspace. Уменьшение service cap само по себе не уменьшает фактическое потребление; Railway считает фактически использованные ресурсы ([правила тарифов](https://docs.railway.com/pricing/plans)).

В код внесено четыре изменения: batch history и индексы, объединение только одинаковых выполняющихся route-запросов, conditional map downloads без уменьшения дневной свежести/покрытия/языков, ограниченное удаление только истёкших quotes/sessions и старых доставленных outbox-записей. Снижение 165→12 SQL для 20 историй подтверждено, но не означает такое же снижение счёта.
