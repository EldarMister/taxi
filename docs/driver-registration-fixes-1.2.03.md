# Исправления регистрации водителя — 1.2.03

## Изменения

- Иконка календаря даты рождения использует основной тёмный цвет в светлой теме, с сохранением контраста в тёмной.
- Каталог марок и моделей отображается виртуализированным `FlatList`: первоначально создаётся до 18 элементов, а не весь каталог. Сортировка использует один экземпляр `Intl.Collator`; результаты фильтрации запоминаются. JSON загружается локально через статический `require`, без неоднозначного `default` динамического импорта.
- Общая нижняя панель поддерживает виртуализированный список, сохраняя прокрутку, закрытие жестом, системную кнопку «Назад» и существующие обычные списки.
- Прежний каталог VehiclesDB заменён независимо собранными данными: GlobalCarModels и Savage3D под MIT, публичными данными NHTSA vPIC и собственным дополнением Atlas для региональных моделей. В интерфейсе нет подписи источника. Лицензионные уведомления включены в APK. Каталог работает офлайн: **250 марок, 4 223 модели**, в том числе Toyota 175 и Honda 94. Мотоциклетные модели NHTSA исключены. Сохранённые значения автомобиля по-прежнему допускаются вне каталога.
- Для года и числового региона используется настоящий Android `NumberPicker` в системном диалоге, с подтверждением и отменой. Значение не меняется при отмене, повторное нажатие не открывает второй диалог. На iOS сохраняется нативный Picker; буквенные регионы прежнего образца используют штатный Android список.
- Регионы нового образца включают **01–11**; 11 обозначает временную регистрацию. Формат номера сохраняет ведущие нули.
- Форма учитывает остаточное перекрытие клавиатурой после Android `adjustResize`. При фокусе поле прокручивается по фактическим координатам поля и области прокрутки, с учётом шапки формы. Это распространяется на номер, серию и обычные текстовые поля регистрации.

## Проверки

- Проверка типов TypeScript — успешно.
- 49 целевых тестов — успешно: выбор/поиск марок и моделей, сброс поиска при смене списка, виртуализация и жесты панели, отмена/подтверждение нативного выбора, защита от повторного открытия, регион 11, форматы номера, черновик, расчёт видимой области при клавиатуре и текущий сценарий регистрации.
- Android debug-сборка с новым нативным модулем — успешно.
- На Android-эмуляторе проверены реальные компоненты формы с тестовыми данными: открытие марок, Toyota → поиск Camry → выбор модели, отмена выбора года, выбор региона 11, номер и буквенная серия с клавиатурой, цвет календаря. В сценарии не возникло ошибки React Native. Временный экран проверки восстановлен; в релиз он не включается.
- Релизная сборка успешно завершена. Проверены `kg.taxigo.driver`, версия `1.2.03`, код `115`, единственная архитектура `arm64-v8a`, рабочий адрес API, наличие нативного модуля и уведомлений, отсутствие временного экрана и ссылки прежнего каталога. Подпись совпадает с предыдущим APK; сжатие нативных библиотек сохранено. Проверка установки arm64 APK на физический телефон не выполнялась: визуальная проверка проводилась в x86_64 эмуляторе.

Готовый файл: `mobile/builds/Atlas-driver-1.2.03-arm64.apk`.
