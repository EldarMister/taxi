# Проверка перехода на OpenStreetMap — 12 сентября 2026

Изменены обе сборки Taxi GO: MapLibre 10.4.2 отображает растровую карту OSM, сервер строит автомобильные маршруты через OSRM и ищет адреса через выделенный Nominatim. Зависимость, плагин, запросы и обязательный ключ Яндекса удалены. Ранее сохранённые заказы сохраняют свою цену; новая котировка рассчитывается по дорожной дистанции OSRM.

Водитель видит свою GPS-позицию и направление. После назначения цель — пассажир, после начала поездки — пункт назначения. Есть следование камеры, возврат к машине после перемещения карты, текст ближайшего манёвра, оставшееся расстояние/расчётное время и русская озвучка. При слабом/устаревшем GPS или ошибке геолокации голос приостанавливается. Пересчёт требует трёх точных отклонений и ограничен по частоте. При завершении, отмене, смене аккаунта и сворачивании старые запросы и голос останавливаются.

## Подтверждено

- TypeScript мобильного приложения и сборка NestJS проходят.
- Мобильные проверки: native — 43, navigation — 18, booking/address search — 29, API — 14, UI — 1, food — 40, auth — 14. Все прошли.
- Сервер: 35 модульных проверок и 24 интеграционных проверки с локальной PostgreSQL. Среди них авторизация/валидация `POST /api/routes` для обеих ролей, котировки, принятие и завершение заказа, неизменность расчётов и комиссия ровно один раз. Сетевые геосервисы в интеграционных тестах заменены контролируемыми ответами.
- Один реальный запрос OSRM в Бишкеке: 4090 метров, 349 секунд, 98 координат и 5 манёвров от `depart` до `arrive`. Это проверка реального маршрутизатора, но не дорожное испытание.
- Android debug APK собраны для `kg.taxigo.app` и `kg.taxigo.driver`, ARM64 + x86_64; подписи v2 проверены. В APK есть MapLibre и нет нативных библиотек прежнего SDK.
- Android JavaScript/Hermes экспорт проверен отдельно от native debug APK. Debug APK не содержит встроенного JS и требует Metro.
- Конфигурация `docker-compose.maps.yml` валидна; образы OSRM/Nominatim закреплены проверенными digest.
- Развёрнуты собственные OSRM и Nominatim в Railway. Импортирован Кыргызстан. Приватный OSRM вернул 1685,8 м и 6 манёвров; Nominatim вернул статус OK и нашёл Бишкек. Два обновления контейнера Nominatim подтвердили сохранение базы и проекта без повторного импорта.
- Рабочий API обновлён: deployment `18506fee-0824-4351-9368-2ec7f3913a09`. Проверка через публичный HTTPS 12 сентября в 04:59 по Бишкеку: клиент и водитель получают маршрут OSRM (1686 м, 48 координат, 6 манёвров), поиск и обратный геокодинг. Котировка использует OSRM и возвращает 100 сом для проверенного тарифа/маршрута. Без токена — 401, некорректные координаты — 400. Заказы не создавались; временные проверочные сессии и котировка удалены.
- До обновления сохранена резервная копия основной PostgreSQL в `.local/backups/taxi-pre-admin-20260911T225430Z.dump`. Все шесть существующих миграций уже были применены; новая миграция для карт не требуется.
- Собраны самостоятельные release APK клиента и водителя: `artifacts/TaxiGO-Client-OSM.apk`, `artifacts/TaxiGO-Driver-OSM.apk`. Встроенный Hermes/JavaScript, рабочий HTTPS API, ARM64 + x86_64, различные package IDs. Подписи v2 проверены; cleartext HTTP в release отключён. Подпись — существующий локальный debug-ключ проекта; это установочные APK, не публикация в магазине.
- Обновлено оформление: приглушённая подложка OSM, трёхслойная синяя линия маршрута, стрелка автомобиля с обводкой и тенью, тёмная панель поворота с расстоянием, временем прибытия и выключателем голоса. Карта учитывает фактическую высоту панели.

Актуальные SHA-256 установочных APK записываются в `artifacts/osm-apk-manifest.json` при проверке каждой новой сборки.

## Исправление поиска в Шамалды-Сае

Широкая область поиска Nominatim отдавалa одноимённые улицы соседних городов выше местной улицы. Теперь общий поиск Кыргызстана дополнен запросом в небольшой области вокруг точки подачи: ближайшие улицы идут первыми, дубликаты убираются. Поиск населённых пунктов остаётся общим, без подмены города названием трассы. Проверены реальные запросы `Ленина`, `Ленина 10`, `Шамалды-Сай` и `Бишкек` при центре в Шамалды-Сае. У двух первых первая запись — улица Ленина в Шамалды-Сае; непроверенный номер дома не приписывается улице.

Мобильный поиск запускается автоматически после паузы 600 мс, начиная с трёх символов. Отдельная кнопка поиска убрана, клавиатура может запустить поиск сразу, повтор после ошибки доступен. Изменение текста отменяет предыдущий HTTP-запрос, запоздалые ответы не отображаются. Новые тесты проверяют приоритет местной улицы, поиск другого города, автоматический запрос после паузы и отмену старого запроса. Серверные тесты — 37, мобильные booking/address — 29; TypeScript и сборка сервера проходят. Исправление опубликовано в Railway deployment `161f7efe-911e-4622-84ec-2fc88701ab98`; четыре запроса проверены через публичный HTTPS с авторизацией, временная сессия удалена.

## Ускорение поиска и опечатки — Photon

Следующий этап заменил текстовый поиск Nominatim на выделенный Photon 1.3.0. Прежние запросы занимали около 1–2 секунд каждый, а `ленена` не давал результатов. Новый индекс Кыргызстана поддерживает неполный ввод и опечатки. Параллельные местный и общий запросы сохраняют приоритет улиц около точки подачи и возможность найти другой город. Одинаковые одновременные запросы объединяются; результаты кешируются. Неподтверждённый номер дома по-прежнему не добавляется к адресу улицы.

Рабочий API deployment `05583e8c-f99a-488a-9579-7edd753bbf0d` использует `PHOTON_BASE_URL`. Через публичный HTTPS с авторизацией проверены десять запросов: `лен`, `ленина`, `ленена`, `ленниа`, `шамал`, `шамалди сай`, `Ленина 10`, `Бишкек`, `бешкек`, `Ош`. Первая запись соответствует Шамалды-Саю либо явно искомому городу. Улица Ленина в этом снимке подписана `Ленин көч`. Первый проход занял 51–469 мс на запрос; повторный с кешем — 26–154 мс. Измерения сделаны из контейнера API через публичный HTTPS и не включают мобильную сеть пользователя или задержку ввода.

После подключения постоянного хранилища и завершения импорта выполнен повторный redeploy Photon `b604ff67-b8b4-4a1f-9a99-47d9b431dff0`: прежние индекс и маркер `import-complete` от 10:32 UTC сохранились, сервер запустился в 10:36 UTC без повторного импорта. Поиск напрямую в Photon и через API проверен после перезапуска. Дополнительно подтверждены маршруты OSRM, обратное геокодирование, котировка и защита API для обеих ролей; тестовые сессии и котировка удалены, количество заказов не изменилось.

Мобильная пауза сокращена до 250 мс, минимальная длина — два символа. Кнопка поиска не требуется. Обе release APK пересобраны со встроенным JavaScript и рабочим API, подписи проверены; актуальные хеши находятся в `artifacts/osm-apk-manifest.json`. Серверные тесты — 42, мобильные booking/address — 30; сборка сервера и мобильный TypeScript проходят. Проверка не означает полное совпадение с поиском Яндекса: результат зависит от наличия улиц и домов в снимке OSM.

## Границы проверки и запуск

После этого отчёта добавлены фоновая навигация, передача положения пассажиру, новый сигнал заказа и исправления камеры/жестов. Актуальные возможности и проверка описаны в [DRIVER-TRACKING.md](DRIVER-TRACKING.md); ограничения фонового режима ниже относятся к предыдущей сборке.

Серверная часть опубликована и проверена. Рабочая конфигурация Railway и порядок обновления: [deploy/README.md](../deploy/README.md). Локальный альтернативный запуск: [server/MAPS.md](../server/MAPS.md). На телефоны APK автоматически не устанавливались. Тайлы изображения карты пока использует публичный OSM; маршрутизация и геокодинг — собственные сервисы. Расходы на серверы Railway остаются.

Автоматическая проверка разрешений заблокировала совместную команду запуска Metro и установки APK в локальный эмулятор с единственным пояснением `blocked by policy`. Команда не выполнилась; установка и запуск приложения в эмуляторе не подтверждены. Не выполнялись также iOS native build, дорожное испытание GPS, прослушивание русского синтезатора и проверка автомобильного Bluetooth. Созданный для теста эмулятор и локальный UI-сервер остановлены.

Навигация работает на открытом домашнем экране водительского приложения и удерживает экран включённым. Фоновое ведение с заблокированным телефоном, пробки, камеры, ограничения скорости и офлайн-маршрутизация не добавлены. Самостоятельные APK уже готовы; debug-сборки первого этапа также остались в `artifacts/osm-client-debug.apk` и `artifacts/osm-driver-debug.apk`.
