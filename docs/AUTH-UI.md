# Поле SMS-кода — 10 сентября 2026

Для установки на телефон используйте [Taxi-GO-android-arm64.apk](../artifacts/Taxi-GO-android-arm64.apk) с публичным HTTPS-сервером. [Проверка подключения и ограничения сервера](CONNECTIVITY.md). APK с суффиксом `auth-local` ниже предназначен только для эмулятора.

Добавление доставки, баннеров и панели управления сохраняет этот интерфейс входа: прежние синие кнопки и иллюстрации, зелёное анимированное поле SMS-кода. Обновлённый API развёрнут в Railway, панель опубликована в приватном режиме Sites. Вход владельца панели выполняется отдельным логином и паролем, а не этим SMS-экраном; сведения находятся в [ADMIN.md](ADMIN.md). Размер и контрольная сумма актуального APK указаны в [CONNECTIVITY.md](CONNECTIVITY.md).

Прежний интерфейс авторизации восстановлен по сохранённой версии до редизайна: логотип, иллюстрации, синие кнопки и ссылки, переключатель языка, подписи и расположение элементов. Разметка и стили за пределами поля кода совпадают с этой версией.

Сохранены изменения только в поле SMS-кода:

- Шесть ячеек без рамок, подчёркивания Android и чёрточек в пустых ячейках.
- Зелёное заполнение, подсветка следующей ячейки и анимация появления цифр.
- Мягкое покачивание при ошибке и выделение кода для замены.
- Зелёная волна после успешной проверки сервером; системное уменьшение движения отключает декоративные анимации.
- Одно нативное поле поддерживает вставку и автоподстановку SMS. Защита от повторных запросов и отмена отложенного входа при закрытии экрана сохранены.
