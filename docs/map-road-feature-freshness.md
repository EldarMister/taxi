# Переходы Шамалды-Сая и свежесть дорожных данных

Проверено 15 октября 2026 года. Серверное исправление опубликовано в Railway deployment `8294c209-e3e0-47f5-bee2-243eb5551652` (SUCCESS).

## Подтверждённые причины

Рабочая версия сервера `6779868e-0aa6-4876-896a-f9e66d49cc6f` содержала прежний модуль дорожных объектов: камера/ограничения оставались в API, а `crossing=traffic_signals` создавал лишнюю иконку светофора. Дедупликация в радиусе 12 метров могла затем скрыть настоящий центральный светофор `2280557714` за иконками переходов. APK 1.2.32 исключал знаки из отображения, но серверный фильтр оставался прежним.

Дата `generatedAt` отражала пересборку JSON, а не актуальность исходных данных. Заголовок используемого PBF содержал `osmosis_replication_timestamp=2026-09-24T20:21:20Z`. Сверка с текущим OSM API выявила 12 отсутствующих объектов в районе скриншотов, включая обычные переходы на Ленина. Дата файла PBF и новая дата JSON не обновляли содержимое исходного снимка.

## Исправление

- Карта выдаёт только переходы и самостоятельные `highway=traffic_signals`. Регулируемый переход не получает дополнительную иконку светофора. Удаляется только совпадение ближе 3 метров, без общего ограничения 2 000 объектов.
- База пересобрана из свежего Geofabrik PBF с исходной датой `2026-10-13T20:21:31Z` и двумя ограниченными выгрузками текущего OSM API по Шамалды-Саю. Получено 6 297 объектов; скоростные участки, камеры и предупреждения сохранены. В JSON отдельно сохраняются исходная дата и области актуальных дополнений.
- Запросы карты и предупреждений проверяют актуальные переходы/светофоры через Overpass. Общий для сервера кэш действует час, одинаковые запросы объединяются, хранится максимум 32 области. Запрос ограничен шестью секундами; ошибка/частичный ответ сохраняет последнюю успешную область или локальный снимок и включает минутную паузу повторов. Глобальной периодической выгрузки нет: обновление выполняется по запросу области.
- В исходниках приложения покрытие дорожных объектов истекает через минуту. При следующем движении карты та же область запрашивается повторно. Эта дополнительная правка клиента пока не пересобрана в APK. Серверная правка уже работает с существующим APK 1.2.32 после повторного открытия карты/приложения.
- `npm run map:refresh` в `server` сначала скачивает актуальный PBF, затем атомарно пересобирает снимок. Для дополнений из OSM API: `python server/scripts/update-road-features.py --overlay current-region.osm`.
- `ROAD_FEATURES_LIVE=false` отключает сетевое обновление. `ROAD_FEATURES_OVERPASS_URL` позволяет использовать собственный совместимый источник при росте нагрузки.

Данные: © OpenStreetMap contributors. Регрессионный fixture `server/test/fixtures/shamaldy-road-features.json` содержит публичные объекты района из OSM API без имён редакторов.

Переходы `14232441042`, `14232441060`, `14232441071`, `14284580895`, `14284580896` и `14214775366` присутствуют; все четыре регулируемых перехода у центрального перекрёстка сохранены и не создают собственных светофоров. Обычные переходы также приходят в предупреждениях маршрута. `/api/health` — 200.

42 серверных теста прошли как в рабочем дереве, так и в подготовленной производственной сборке; Python-тест извлечения и TypeScript прошли. Семь целевых проверок приложения прошли, включая истечение покрытия, повторную загрузку той же области и сохранение разметки при ошибке сети.

Хеши 106 прежних файлов сервера, включая авторизацию, адресный поиск, расчёт маршрута и миграции, сохранены. Изменены только модули дорожных объектов/контроллера и снимок; добавлен модуль обновления. Опубликованные файлы совпадают с проверенной сборкой, записи миграций не изменились. Временная проверочная сессия удалена, её токен отклонён, временный SSH-ключ снят.
