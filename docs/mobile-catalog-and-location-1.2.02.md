# Atlas 1.2.02 — марки, числовые селекторы и местоположение

## Изменения

- Строки марок увеличены с 33 до 48 логических единиц. Слева добавлены логотипы одинакового визуального размера, с сохранением пропорций и исходных цветов.
- Сверху раздел «Популярные»: Toyota, Honda, Hyundai, Kia, Chevrolet, Daewoo, BMW, Mercedes-Benz, Лада (ВАЗ), Mazda, Lexus, Nissan, Volkswagen, ГАЗ, Volvo, Ford, Subaru. Ниже раздел «Все» по алфавиту. При поиске показан единый список без повторов; работают русские названия Лада/ВАЗ и ГАЗ, а также латинские варианты.
- Каталог расширен с 94 марок / 1829 моделей до 422 марок / 7136 моделей. Toyota: 189, Honda: 127, Mercedes-Benz: 571, Daewoo: 21, Лада: 40, ГАЗ: 18. Каталог объединяет легковые автомобили, фургоны и грузовики; комплектации и модельные годы не выдаются за отдельный обязательный справочник.
- Локально включены 183 соответствия марки логотипу, включая все 17 популярных марок. Для редких марок без доступного логотипа используется нейтральная контурная иконка автомобиля. Логотипы не загружаются по сети во время выбора.
- Нативные селекторы года и региона сохранены. Добавлены нативные числовые списки для грузоподъёмности, паллет, грузчиков и температуры. Существующие произвольные значения включаются в список; пункт ручного ввода сохраняет прежние допустимые диапазоны. Дата рождения использует системный календарь. Номер автомобиля, телефон и код подтверждения остаются строковыми полями с подходящей клавиатурой.
- Клиентский индикатор положения переведён на `UserLocation` MapLibre с `renderMode="native"`, Android-режимом `compass` и указателем направления. Удалён отдельный маркер приложения. Обновления GPS, ручной выбор места подачи, наведение камеры и отображение водителя сохраняются.
- Удалены 17 подтверждённо неиспользуемых изображений: прежние изображения направлений регистрации, старые варианты машин и еды, PNG положения пользователя и исходные устаревшие дорожные иконки. Рабочие ресурсы из `road-signs/`, изображения услуг, логотипы приложения и onboarding-разрешений сохранены. Удаление неиспользуемых исходников уменьшает репозиторий; основной выигрыш в APK получен упаковкой библиотек.
- Версия обеих сборок — 1.2.02, Android-код — 114. Добавлен `npm run version:bump`: синхронное повышение Expo и Android перед новым выпуском, с переходом 1.1.99 → 1.2.00. Обе разновидности приложения собираются с одной версией выпуска; повторные попытки сборки внутри этого выпуска не повышают её.
- Включено сжатие нативных библиотек в APK (`useLegacyPackaging`). Оно уменьшает скачиваемый файл; Android распаковывает библиотеки при установке. Возможности приложения и состав архитектур сохранены. Дополнительные варианты для будущего уменьшения — оптимизация используемых крупных изображений и проверенное включение R8; в этом выпуске они не применялись.

## Проверки

- TypeScript мобильного приложения: успешно, включая последние изменения.
- 102 целевых теста онбординга, регистрации, карты, жизненного цикла и конфигурации вариантов: успешно.
- Дополнительная проверка повышения версий, включая переход `.99`: успешно.
- Тесты проверяют порядок популярных марок, наличие их логотипов, высоту строк, поиск по ВАЗ, полноту моделей, связанные выборы марки/модели, независимое сохранение, нативные числовые значения и ручной ввод без новых ограничений.
- Проверки карты выполняют GPS-обновление против настоящего компонента: включён нативный индикатор и направление, камера получает новое положение, ручной адрес подачи не меняется, водитель сохраняет собственный поток положения.
- Старые изображения проверены на отсутствие ссылок в рабочем коде и конфигурации перед удалением. Сборка проверяет разрешение всех оставшихся ресурсов.
- Обе сборки — только `arm64-v8a`; production API сохранён. Подпись APK проверяется тем же ключом обновления приложения.

В этом проходе новый индикатор карты не запускался на физическом телефоне. Проверены его свойства, GPS-сценарии и совместимость с установленной нативной версией MapLibre; нативный внешний вид определяется SDK и доступными датчиками устройства.

## Источники

- [VehiclesDB](https://github.com/vehiclesdb/vehiclesdb): каталоги `car`, `van`, `truck`, снимок от 7 октября 2026. CC BY 4.0, лицензия и upstream-уведомления сохранены в проекте и APK. В панелях есть компактная ссылка с указанием источника.
- [Global Car Models](https://github.com/serhatkildaci/global-car-models): исходный каталог сохранён при объединении для совместимости, MIT.
- [Официальный дилер ГАЗ](https://www.avtogaz.ru/models/): проверенные наименования текущих коммерческих моделей.
- [Car Logos Dataset](https://github.com/filippofilip95/car-logos-dataset): логотипы, подготовленные для локального использования. Товарные знаки принадлежат владельцам.
- [Android: упаковка нативных библиотек](https://developer.android.com/reference/tools/gradle-api/8.2/com/android/build/api/variant/JniLibsApkPackaging).
